# Responsive Design Tokens & Mobile-First CSS Architecture

**Student Project – Responsive Dashboard**

## About the Project

This project is part of my web development learning. I created a responsive dashboard using HTML5 and CSS3 to understand how websites can adjust to different screen sizes.

The main aim of this project is to learn about CSS design tokens, Flexbox, CSS Grid, and mobile-first design. I have also used different colors, spacing, and layouts to make the dashboard look clean and easy to use.

## Features

- Responsive dashboard layout for mobile, tablet, and desktop screens.
- CSS variables to manage colors, font sizes, spacing, and border radius.
- CSS Grid and Flexbox for arranging dashboard sections.
- Dashboard cards to display sample information.
- Chart-style bars and progress indicators.
- A project table to display sample project details.
- Simple design with background colors, rounded corners, and shadows.
- Keyboard focus styles to improve accessibility.

## Technologies Used

- HTML5
- CSS3
- CSS Custom Properties
- CSS Grid
- Flexbox
- Visual Studio Code
- Live Server extension

## Project Structure

- `index.html` – contains the structure and content of the dashboard.
- `style.css` – contains the design, layout, and responsive CSS rules.
- `README.md` – provides information about the project.
- `screenshots/` – used to store screenshots of the dashboard at different screen sizes.

## How to Run the Project

1. Download and extract the project folder.
2. Open the folder in Visual Studio Code.
3. Open the `index.html` file.
4. Right-click the file and select **Open with Live Server**.
5. The dashboard will open in your web browser.
6. Resize the browser window to check how the layout changes on different screens.

No additional packages or installations are required apart from a code editor and browser. Live Server is optional, but it makes testing easier.

While working on this project, I learned how to use CSS variables to maintain consistent styles and how to create layouts using Grid and Flexbox. I also understood the importance of responsive design and tested how a dashboard can adapt to different screen sizes.
